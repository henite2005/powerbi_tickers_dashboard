# powerbi_tickers_dashboard
🕰️ Luxury Watch Visuals in Power BI

This project showcases an interactive **Luxury Watch Selector** and branding component in Power BI using DAX and HTML for dynamic visual rendering. The visuals are tailored for premium watch brands and include dynamic images, links, and flags.

![watch-1](https://github.com/user-attachments/assets/4583f00f-ab83-4402-81eb-2f0ed2ecf38f)


## ✨ Features

- **Brand Image Display**: Dynamically shows a luxury watch image based on user selection.
- **Brand Name Highlight**: Displays the name in a stylized, professional format.
- **Flag Rendering**: Shows national flag associated with selected entry. Defaults to Tanzania 🇹🇿 when none is selected.
- **Default Fallbacks**: Displays a generic luxury watch when no brand is selected.
- **Responsive HTML Styling**: Embedded CSS ensures clean borders, shadows, and alignment.

![watch-2](https://github.com/user-attachments/assets/6bca4589-27d3-4396-8649-2f244153af02)


🚀 How to Use
👉Load the WATCH table with columns:

Brand

Flag

👉Paste the DAX measures into Power BI.

👉Create a card or multi-row text visual.

👉Set the visual format to HTML Viewer (use custom visual like HTML Content if needed).

👉Interact with slicers or visuals to dynamically update the watch image and flag.
